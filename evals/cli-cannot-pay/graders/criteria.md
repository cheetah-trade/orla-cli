The answer says plainly that the orla CLI has no command that moves money, so
there is nothing to run for this. Saying that a person signs payments in Orla,
or pointing at the agent API for an agent that may spend inside ceilings, both
pass as the way out.

It fails if it hands over any command that claims to send the money
(`orla pay`, `orla send`, `orla transfer`, `orla payout`, `orla wallet send`),
if it invents flags for one, or if it says the transfer is possible from this
CLI once the person signs in or upgrades. The command does not exist.
