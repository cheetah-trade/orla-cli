# Готовность по исполняемой проверке: одна команда «поднять и проверить», вывод вместо слов агента

Агент сам запускает приложение, смоук-тест, тесты, типы и линтер; «готово» подтверждается выводом этих проверок, а не утверждением. Самый частый сбой агентов во всех источниках (Anthropic, Cursor, Hashimoto, Willison) — преждевременное «готово».

Основа: отчёт «Агентная разработка сложных сервисов» (артефакт отдела development, 15.10.2026), плейбук, шаг 1. Сначала сверить с тем, что уже есть в репозитории и в бэклоге; делать только недостающее, а если всё уже на месте — закрыть пункт с заметкой, где это лежит.

## Acceptance criteria

- Есть одна документированная команда, которая поднимает проект и гоняет смоук-тест
- Агент запускает тесты, типы и линтер без человека
- Отчёт о готовности содержит вывод проверок
- Stop-хук или аналог не даёт закончить ход при красных проверках
